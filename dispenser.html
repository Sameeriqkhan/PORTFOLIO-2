Automatic Water Dispenser

Two-ESP32 system for plant watering with moisture sensing, pump control, and a simple UI on Adafruit IO. Designed for reliable hydration without over-watering.

ESP32 Moisture Sensor (I²C) Adafruit IO Pump & Enclosure

Problem

Inconsistent manual watering → stressed plants. Needed a simple, reliable automation.

Approach

ESP32 + I²C moisture sensor for thresholds; second ESP32 drives pump; UI + logging via Adafruit IO.

Result

Consistent soil moisture with fewer false triggers; easy dashboard control and history.

Build Notes

  • Architecture: Sensor node publishes moisture level; controller node actuates pump based on threshold + UI command.
  • Safety: Minimum cool-down between runs; max run time per cycle; basic dry-run protection.
  • Enclosure: Printed brackets and splash-resistant routing for tubing and wiring.
  • Observability: Moisture % and pump events logged to Adafruit IO for trend checks.
